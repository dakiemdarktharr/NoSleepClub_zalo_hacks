# ADR-0006: integrated Windows Rust runtime

Date: 2026-11-01. Status: implemented, with release gates in [validation](../validation.md).

NORA uses a native eframe/egui user-session tray application rather than a resident browser or Python worker. The supervisor owns microphone, playback, API credentials, durable goals and permission decisions. Typed channels separate UI commands, untrusted model proposals and native inference outputs. Starting the application does not start recording or call a model.

The LLM is remote: OpenAI Responses, the user's exact `gpt-6-luna` model and `xhigh` reasoning setting. One orchestrator is admitted at a time. Public research uses a separate bounded model context after a query preview; its outputs are evidence, never permission. Hidden reasoning/opaque continuation items remain in memory and are not exposed as progress messages. The app has no LangGraph, Temporal, local LLM or resident Python dependency.

Local audio uses Silero VAD, Whisper large-v3-turbo Q5 and unchanged VieNeu v3 Turbo FP32 graphs with native G2P and ONNX Runtime CPU. One ASR/TTS worker is resident at a time. The pinned whisper.cpp CMake defaults require explicit AVX, AVX2, F16C and FMA flags when `GGML_NATIVE=OFF`; otherwise a scalar build can pass tests while transcribing too slowly. Runtime feature checks reject unsupported CPUs. ASR uses at most eight available threads; TTS retains bounded CPU threads. This baseline favors broad deployment without a CUDA runtime or local GPU model allocation. It does not establish a quality/latency SLO for all laptops.

The root Windows Job Object enforces a 2,000,000,000-byte commit budget. Each native worker additionally has a 1,700,000,000-byte, one-process nested job and a fresh zero-capability AppContainer. Only selected executable/asset roots receive package-SID read/execute ACLs; a fresh scratch root receives modify access. No extra handles or API-key environment variables are inherited. `LOCALAPPDATA` and `SystemDrive` are required parts of the explicit Windows environment. Package-SID grants suffice for selected medium-integrity resources; setup does not relabel user files as low integrity. See [Microsoft's AppContainer documentation](https://learn.microsoft.com/en-us/windows/win32/secauthz/implementing-an-appcontainer) and [Chromium's Windows launcher environment](https://chromium.googlesource.com/chromium/src/+/04d774d3827c8532b1b7d3966629f9193a35dd0e/sandbox/win/src/target_process.cc).

Cleanup leases are written before child setup, bound to PID plus process creation time, and recovered only after exclusive supervisor ownership. Recovery does not kill an unrelated process that reused a PID. Reparse/retarget checks precede ACL cleanup. Negative controls verify readable scratch, denied outside files/writes, blocked localhost access with a working parent control, filtered environment and successful profile/ACL removal. A timeout is distinguished from a specific socket access-denied error.

The user chooses folder read/create/cloud-disclosure grants and registers executable hashes. Actions require exact, expiring, one-use approval previews. Notes are create-new only and read back before completion. Approved external applications run outside NORA's job and budget; arbitrary GUI automation, shell execution, command arguments, deletion and message sending are absent. Unknown external effects require reconciliation.

The original goal is persisted before admission is acknowledged. Follow-up input gets a durable hash marker before enqueue; a crash requires restatement rather than silently losing acknowledged instructions. Checkpoint consumption uses compare-and-delete. Waiting approval recovers to an explicit resume state; the prior approval is not reused. Final results are retained separately for local display and are not restored as model authority.

Notifications are based on trusted lifecycle events. Questions, approvals, material blockers/findings and verified completion can be spoken; generic acceptance/completion milestones do not create duplicate narration. Technical logs/epochs/skill initialization stay silent. Withdrawn questions/approvals cancel their own queued or in-flight audio. A notice retires when its selected speech channel finishes, or its visible surface is acknowledged when speech is disabled/skipped. Channels are recorded separately; cancelled audio never gets a fabricated delivery acknowledgement. Playback drain is software evidence, not proof a human heard it.

Resource receipts sum concurrently sampled working sets/private bytes for the actual root Job PID set. They do not add unrelated lifetime process peaks. GPU counters are separately sampled across adapters; a low observed allocation is not certification on a physical 4 GB GPU. The portable package is counted by logical file sizes, including hardlinked assets. Developer toolchains/build caches are outside installed-runtime disk scope. Filesystem quotas, signed distribution/updates, clean-machine testing and representative live Vietnamese microphone evaluation remain separate release gates.
