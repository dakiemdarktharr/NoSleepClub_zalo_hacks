# NORA desktop integration

Status: unsigned validation candidate, 2026-11-01. This document records implemented scope, not a production certificate. Whole-product evidence and remaining gates are in [validation](validation.md); the detailed design is in [ADR-0006](adr/0006-integrated-rust-runtime.md).

Windows x64 runtime: native Rust eframe/egui shell, tray and Ctrl+Shift+Space push-to-talk. It opens neither microphone nor network merely by starting. WAV import requires a local picker and disclosure confirmation. Supported WAV inputs are mono/stereo PCM16 or float32, at the supported resampler rates, within the recording-duration limit. No Python runtime is required.

Pipeline: PTT → bounded capture/Silero → isolated Whisper large-v3-turbo Q5 ASR → trusted goal admission → OpenAI Responses (`gpt-6-luna`, `xhigh`) → typed broker tools/explicit approvals → receipt and checkpoint verification → bounded text/voice updates → isolated VieNeu FP32 inference → local playback. ASR/TTS model residency is serialized. LLM hidden reasoning and opaque continuation items stay out of UI, persisted checkpoints and logs.

Place `nora-app.exe` in an isolated `bin/`, verified voice assets in sibling `assets/`, and credentials in sibling `config/.env.local`. Copy [.env.example](../.env.example) and edit locally; never paste the key into chat. Run `nora-app.exe --config APP.json`, where the bounded JSON config supplies `state_dir`, `asset_root`, `llm_config`, `quiet`, `public_research` and `max_recording_seconds` (1–60). State/config must remain outside native worker read roots. The standard default state location is `%LOCALAPPDATA%/NoSleepClub/NORA/state`.

```powershell
./scripts/Build-Rust.ps1 -Action Release
./scripts/Prepare-VoiceAssets.ps1 -Destination D:/nora-assets
./scripts/New-NoraPortable.ps1 -Executable ./target/x86_64-pc-windows-msvc/release/nora-app.exe -AssetSource D:/nora-assets -Destination D:/NORA
```

Edit `D:/NORA/config/.env.local` locally, then run `D:/NORA/Launch-Nora.cmd`. Setup requires PowerShell 7; the app does not. Portable packaging can optionally reference an existing private `-LlmConfig` file without copying its contents. `-HardlinkAssets` is a local same-volume option; logical disk accounting still counts the complete asset sizes. The application needs AVX2/F16C/FMA, an OpenGL 3.3-compatible driver and the Microsoft Visual C++ x64 runtime. The script produces an unsigned local package, not a public redistribution clearance.

The example config explicitly allows 96,000 input tokens per goal, with 24 calls and 12,000 output tokens shared by the orchestrator and research workers. These are spending ceilings, not promised usage or a local RAM allocation. A real research-to-note test with a 48,000-token ceiling wrote/read back the approved note but correctly stopped before its final reply because the next conservative reservation did not fit. Lower budgets remain valid; reaching them stops new requests without inventing completion. No silent budget increase or retry is performed by the app.

Folders are selected by the user, with separate read/create and cloud-disclosure permissions. Read/list/search operate only on such roots; local-only contents are not admitted into cloud tool outputs. Notes use create-new semantics and exact previews. Applications must be selected as EXE files, registered by content hash, and explicitly approved before launch; no shell, command arguments or message-send tool is exposed. Calculator, local time and durable reminders are also available. Public web research is opt-in and has a separate query preview. This scope does not include arbitrary app GUI automation, Zalo account login, OA message sending, or a contest submission generator.

Pause/cancel/stop-speech are distinct. Voice controls include “Nora ơi, tạm dừng mục tiêu”, “hủy mục tiêu”, “tiếp tục mục tiêu”, “đến đâu rồi” and “dừng nói”. Interrupted speech is never logged as delivered. Explicit status requests bypass routine-update cooldown. Reminders are software-delivery acknowledgments, not proof the user heard or read them.

The microphone is push-to-talk, with a separate discard-recording/transcription action. A spoken answer while the current goal is waiting for input is routed to that same goal. Stop-speech does not cancel the goal. Completed/recovered goals expose their full locally stored result without another API call. Quiet/public-research preferences survive restart. API/key/voice errors keep accepted goals or return rejected input to the draft rather than claiming success.

Native model workers use fresh zero-capability AppContainers, an explicit environment/handle allowlist, a separate scratch directory and nested one-process job. A parent2,000,000,000-byte commit cap and child1,700,000,000-byte cap are enforced. Job commit counters and physical working-set measurements are distinct. Disk/watchdog limits are not kernel filesystem quotas. User applications opened after approval run outside NORA's budget and must be reported separately.

Build/test: `./scripts/Build-Rust.ps1 -Action Test`, `Clippy`, `Release`; pinned toolchain and existing MSVC/CMake/Ninja are required. Windows/Linux CI checks are configured, with real Windows memory-refusal and AppContainer negative controls. Windows CI artifacts contain unsigned EXEs, notices and synthetic probe receipts; voice assets, DLLs, credentials and user state are excluded.

`--doctor` checks configuration/assets without networking. `--api-probe` explicitly makes a billable synthetic request. `--live-check` checks calculator, approved note write/readback, missing-input cancellation and restart recovery; setting `public_research=true` in its test config additionally runs approved public research to a note. `--voice-check SYNTHETIC.wav` expects the documented “Xin chào, tôi là Nora” fixture and tests spoken follow-up on the same goal. These checks use isolated synthetic state and can incur API charges. `--resource-probe` checks OS allocation refusal; `--sandbox-check` checks allowed/denied filesystem/environment/network access.

`scripts/Measure-Nora.ps1` launches the real desktop with `--metrics`, optionally imports a caller-selected WAV, captures only its own egui framebuffer, and reports separately sampled GPU counters. Inspect durable goal and speech results in addition to exit code and memory peaks. The diagnostic exit deadline is not a functional acceptance assertion. No microphone is opened by this harness.

Release gates still require clean-machine installation, a representative live Vietnamese microphone corpus, AEC/far-field and physical-device testing, the exact-build dependency/asset license bundle, signed distribution/update policy and broader failure/soak tests. Intent acceptance checks are bounded heuristics plus verified tool receipts, not a general natural-language proof. Unknown app/reminder effects require reconciliation rather than blind retries. Integrated synthetic evidence is recorded separately from the historical component benchmark.
